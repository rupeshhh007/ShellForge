# Independently authored safety benchmark

`safety_authored.tsv` contains labels and operation-based justifications authored before evaluation, not generated from validator output or imported heuristic labels. Three classes: SAFE for ordinary read-only examples; CAUTION for bounded mutation, sensitive/network/privileged or unknown behavior; DANGEROUS for recursive deletion, truncation, formatting, arbitrary code execution, broad permissions, forced termination, and invalid proposals. Labels are policy-specific and authored by the implementation assistant, not an external expert consensus. Benchmark cases are excluded from training. They are not a random population sample; perfect benchmark performance cannot imply universal safety. Commands are analyzed and syntax-checked only, never run. Known false negatives remain visible in evaluation outputs rather than relabeled.
