# Active direction — Interactive Command Laboratory

The 2026-10-22 redesign uses the supplied Scribo images as primary art direction:
cream #F5EFE4, evergreen #073F34, forest #096447, yellow #F8CA39, pink #F277AD,
cobalt #7399F3 and ink #102A29. Manrope handles readable expressive headings and
controls, Instrument Serif occasional italic emphasis, IBM Plex Mono technical text.
The three main experiences are Forge, Lab and Model Studio; Research retains the
formal record. X-Ray and Field Manual remain direct tools, not more primary tabs.

State-driven motion includes actual matches/diffs, interpreter event playback,
shared-layout focus dialogs, process chips, token focus and actual saved prediction
comparisons. A restrained fine-pointer ring is disabled on touch, reduced motion
and text controls. Native dialog provides focus trapping, Escape, scroll locking
and focus restoration; mobile dialogs fill the screen.

Original generated terminal artwork is optimized to WebP with alpha. Tool controls,
values, permission bits and scheduling remain native code. Concept images contain
illustrative values that are deliberately replaced with real fixture and artifact
data. See ASSETS-AND-CREDITS.md for generation and fidelity notes.

# The Command Workshop

## Active visual specification — revision 3

The user rejected the first flat bone/copper interface and requested much stronger
motion. The active generated references are `concepts/landing-v3.webp`,
`concepts/workbench-v3.webp` and `concepts/precision-v3.webp`. Earlier concepts are
historical, not the current specification.

Color lock: graphite #111311, warm white #f1f2e9, acid signal #d5fb5a, muted #a5aba0,
rules #373c34. The transformation chapter uses bone #eeece5. Manrope's bold, tightly
set headings lead; Instrument Serif is reserved for selected editorial phrases.
IBM Plex Mono carries command syntax. Controls are deliberately larger than the
rejected design. Thin rules and open compositions replace repeated cards.

The opening copy is “Know what / you’re running.”, followed by “Turn an intention
into Bash. Take every command apart. Decide what happens next.” Actions are “Enter
the Forge” and “Inspect a command”. A native six-piece command assembly uses original
generated graphite material rather than a flattened product screenshot. Each plate
is selectable by mouse or keyboard; its caption describes real GNU find semantics.
Assemble/Pull apart changes the arrangement. The mobile layout stacks copy and
assembly; all six controls remain reachable.

Forge and X-Ray retain their real request contract, environment selector, error and
unsupported states. Input and guidance share a desktop row; command and inspector
are resizable adjacent panels. Mobile uses explicit Command/Inspector tabs. The
sequence below the command shows actual token order, not an invented AST tree.
Syntax, policy and execution remain separate facts. Manual and Bench share the
new type/rule system and preserve their catalog and research data.

## Motion

Motion for React remains the only runtime. The heading reveals through clipped
lines; six independent plates enter on staggered springs. Pointer depth, spring
hover lift, Assemble/Pull apart and scroll-linked rotation create visible motion.
Chapter content reveals with a larger translation and brief blur. Chapter selection
travels on a spring. Route changes open through a short signal-color shutter.

The command receipt reveals only after real HTTP completion. Tokens assemble in
sequence, selection moves a shared-layout highlight, and explanation text exchanges
with directional motion. The pending indicator exists only while an API request is
outstanding. Hover effects use CSS; no fake computation or progress is displayed.
Reduced motion disables the curtain, scroll transforms and smooth scrolling while
leaving every control and chapter readable, including before hydration.

## Intentional differences from generated concepts

The generated concepts are composition specifications, not authority for new
features or claims. No account avatar, theme toggle, docs action, duplicated OS
controls, fake AST hierarchy, or blanket read-only safety guarantee was added.
The existing navigation and native OS select remain. The hero's material is an
original raster texture mapped onto independently animated HTML plates, preserving
real text and keyboard access. The first-viewport composition is adapted to keep
copy and moving plates from obscuring one another. Extra helper labels identify the
interactive anatomy study rather than claiming a generated result. Existing receipt
assumptions and policy findings stay visible even when they make the page taller.

## Reference investigation (21 October 2026)

- [Onlines](https://onlines.com.ar/): inspected the live narrow viewport, scrolling
  from the collage hero to a progressive text reveal and project panels. Generous
  scale and scroll-paced contrast inspired chapter rhythm. No collage artwork,
  role labels, cursor branding or copied layout is used.
- [Francesca Noemi Marconi](https://www.francescanoemimarconi.it/): inspected the
  desktop hero, Experience anchor transition and timeline controls. Serif/mono
  contrast and editorial reading pace informed type hierarchy. No characters,
  personal narrative, markup decoration or artwork is reused.
- [Rare UI Rail TOC](https://www.rareui.com/components/railtoc): read documentation,
  registry, published source and license. The live IAB gallery was blocked by a
  Vercel checkpoint; a later browser interaction timed out. No claim of live Rare
  demo testing. Our reduced chapter rail adapts its spring/selection pattern,
  with visible credit and the full license retained. It has no paper plane.
- [Bencho resizable panels](https://bencho.dev/blocks/resizable-panels): inspected
  the actual preview, two/three panel settings and keyboard-ready divider. Keyboard
  automation subsequently timed out, so its keyboard behavior was not verified.
  [Code Reveal](https://bencho.dev/blocks/code-reveal) is an ASCII image hover effect,
  not a command generator. Do not transplant it into command output. Source access
  is account/plan dependent; the licence page did not expose full terms in fetched
  content. No Bencho source is copied. Our original resizer uses Pointer Events and
  native keyboard semantics; original token reveal uses Motion.
