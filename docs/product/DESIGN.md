# The Command Workshop

## Visual specification

The generated concepts in `concepts/landing.webp` and `concepts/workbench.webp`
establish the composition. A bone paper surface, charcoal code instrument and
copper precision marks connect five routes. Instrument Serif gives large headlines
contrast against Manrope controls and IBM Plex Mono command text. Headings have
deliberately tight tracking; paragraphs stay under 65 characters. Thin rules and
open editorial layouts replace repeated cards. The primary action is rectangular.

Landing: enormous two-line headline on the left, original copper/silver sculpture
on the right; dark interactive command strip beneath. Follow with the one-character
comparison, request-to-intent transformation, then a three-part verification chapter
and direct invitation to the Forge. The product is accessible from the first view.

Forge/X-Ray: a large editorial heading; request, profile and submit on one line at
desktop; a single dark command surface adjacent to a bone token inspector. Intents
and policy findings are separate. Mobile uses explicit Command/Inspector tabs;
only code regions can scroll horizontally. No execution affordance exists.

Field Manual is a searchable typographic index with expandable parameter controls.
The Bench is a research article with a genuine comparison table and separate safety
evaluation. These content surfaces share the same type, rules and margins.

## Motion

One runtime, Motion for React: short staged hero entrance, bounded pointer tilt,
chapter reveals on entry, spring-positioned chapter rail. Never hide content behind
a loader. The command reveal starts only after actual HTTP completion. Busy state
means an API request is pending, not simulated model computation. Token selection
and receipt transitions clarify actual state. CSS handles hover/focus feedback.
Reduced motion disables transforms and smooth scrolling. No perpetual animation.

## Reference investigation (21 October 2026)

- [Onlines](https://onlines.com.ar/): inspected the live narrow viewport, scrolling
  from the collage hero to a progressive text reveal and project panels. Generous
  scale and scroll-paced contrast inspired chapter rhythm. No collage artwork,
  role labels, cursor branding or copied layout is used.
- [Francesca Noemi Marconi](https://www.francescanoemimarconi.it/): inspected the
  desktop hero, Experience anchor transition and timeline controls. Serif/mono
  contrast and editorial reading pace informed type hierarchy. No characters,
  personal narrative, markup decoration or artwork is reused.
- [Rare UI Rail TOC](https://www.rareui.com/components/railtoc): read documentation,
  registry, published source and license. The live IAB gallery was blocked by a
  Vercel checkpoint; a later browser interaction timed out. No claim of live Rare
  demo testing. Our reduced chapter rail adapts its spring/selection pattern,
  with visible credit and the full license retained. It has no paper plane.
- [Bencho resizable panels](https://bencho.dev/blocks/resizable-panels): inspected
  the actual preview, two/three panel settings and keyboard-ready divider. Keyboard
  automation subsequently timed out, so its keyboard behavior was not verified.
  [Code Reveal](https://bencho.dev/blocks/code-reveal) is an ASCII image hover effect,
  not a command generator. Do not transplant it into command output. Source access
  is account/plan dependent; the licence page did not expose full terms in fetched
  content. No Bencho source is copied. Our original resizer uses Pointer Events and
  native keyboard semantics; original token reveal uses Motion.

## Practical changes from generated concepts

Generated concepts are composition references, not authoritative product claims.
The implementation retains honest static-policy wording and explicit limitations;
it does not use the concept's suggestion of personalized rules. The standalone
hero asset differs from the concept sculpture but retains its material/lighting
family. Original vector syntax drawings add the secondary visual family. Browser
screenshots are the acceptance evidence, not concept images.
